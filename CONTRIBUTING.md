# Contributing

1. Fork + Branch (`feat/...`)
2. Grün müssen sein: `npm install && npm run lint && npm run test:cov && npm run build`
3. Neue Logik nach TDD (RED → GREEN → REFACTOR); Tests liegen in `tests/`, gespiegelt zur Quellstruktur
4. Coverage-Gate nicht senken — `npm run test:cov` muss ohne Threshold-Fehler durchlaufen
5. PR mit Beschreibung + Screenshot bei UI-Änderungen
